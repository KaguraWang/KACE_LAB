## 三段冷凝联合求解增量

新增 `TransientCondenser` 将有限蒸气流的去过热/潜热/过冷曲线与有限热容壁面、水套联立，而非将两套算法移热结果相加。

1. 用零蒸气供热预测壁面本步末的最低温度。
2. 原三段求解器新增严格恒温壁边界（数学上冷侧热容率趋于无穷，而不是伪造超大冷却水流量），求可移热上界。
3. 对热量二分：给定移热量求壁面末温，再用这一末温求蒸气实际能释放的热量，直到一致。
4. 返回共同热量下的凝结/逸散流率、产品温度、水套/壁面末温和全部热量账本。缺少物性范围时拒绝，不外推。

储热层新增指定热量入口，禁止同时开启另一热侧热导，以免重复注入能量。无蒸气时仍推进已热壁面向冷却水和环境的散热。

TransientCondenserAudit 140/140：水/甲醇/乙醇×三时间步×三冷却流量，热流一致、冷热总账、蒸气质量、温差方向；恒温壁完整冷凝后过冷解析对照；闭水套1000秒升温导致冷凝减弱；停汽后的余热散去；重复热源拒绝。容量/热导仍为明确的合成夹具值。**本增量仍是数学层联合，未更改运行时装置行为**，整机接入及真实参数仍是下一步。

## 守恒模型

玻璃壁与充分混合水套各有独立温度和正热容，热容、接触热导及环境热导都由调用者提供。没有把审计里的合成数值当作玻璃材料数据或实测装置参数。

对时间步 dt，两节点采用隐式欧拉：

- C_wall ΔT_wall = dt [K_hot(T_hot−T_wall,new) − K_water(T_wall,new−T_water,new) − K_air(T_wall,new−T_air)]。
- C_water ΔT_water = dt [K_water(T_wall,new−T_water,new) − ṁCp(T_water,new−T_inlet)]。

两个线性方程联立求解。返回热侧移热、冷却水携走、环境散热、壁面蓄热和水套蓄热，所有账本使用同一步末热流。热流保留符号，热环境可向装置传热，不随意删掉负值。无水流不等于无冷却水：已有水套继续蓄热，外流带走热量为零。

数值采用温差增量而非大绝对焓相减；舒尔补按正项展开，避免大热导下相消。非法输入和溢出不返回半成品状态。零步长保持原状态。

`TryStepLimited` 给定本步蒸气可供热量上限，通过缩小热侧有效接触热导求解，不在解算后裁剪热量，防止储能和账本不一致。此上限仅限制热侧向壁面供热；逆向传热仍须由未来调用者正确登记到真实热侧库存。没有蒸气接触时调用者应显式设置HotWallWPerK=0。

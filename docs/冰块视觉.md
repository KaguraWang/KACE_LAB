# 冰块视觉与验收边界

## 当前实现

- water_ice 使用闭合、不规则圆角块，按三角网格实际体积和物质密度缩放，圆角不会减少账本中的冰质量。
- 冰和其他固体使用独立子网格、独立材质。普通粉末、金属、沉淀不受透明渲染影响。
- Ice.shader 使用屏幕背景采样的透射与折射，几何起伏和连续法线扰动改变背景采样位置，并加入掠射边缘反光及少量内部霜纹。
- 使用已有深度保护，避免把前景物体折射复制到冰面。
- 参数是实时教学渲染近似，不是完整光线路径追踪，不支持屏幕外背景或多冰块之间完整多次折射。
- 堆放使用保守几何包围盒和支撑高度，不是刚体接触解算。真实浮力、液体排开以及冰与GPU流体双向耦合仍待做；不能通过增加液水库存或任意抬高冰网格来伪造。

## 验收

SolidAudit 检查三种器皿的 0.1/5/10/20g 冰体积、边界和材质标记，并检查烧杯中冰块的底部/下层支撑；当前共389项通过。

InteractionRegression 检查实际Player中独立折射shader受支持、两相存在与转移潜热守恒。额外 AuditIceOptics 使用棋盘背景分别渲染折射开启、折射关闭、移除冰以及旧不透明材质四个控制画面，检查折射产生可测图像差异，以及透射背景保留优于不透明对照。

初次对照测试使用内置Unlit/Texture，在Player被剥离导致测试夹具异常。现改为显式Resources中的OpticsAuditBackground，仅测试使用；不改变已获认可的冰外观。最终运行结果见CURRENT_GOAL.md。

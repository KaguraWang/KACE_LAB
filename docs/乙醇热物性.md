# 纯乙醇焓曲线与数据范围

本模块为后续有机物冷凝提供液相焓基础，现已用于纯乙醇倾倒混温。**蒸馏运行时目前还没有使用它**，不能据此宣布乙醇完整能量冷凝完成。

## 来源与采用方式

- [NIST SRD69 乙醇](https://webbook.nist.gov/cgi/cbook.cgi?ID=C64175&Mask=16)：298.15 K 液相比热容112.4 J/(mol K)，摩尔质量46.0684 g/mol；351.5 K汽化焓38.56 kJ/mol。
- [Fiock、Ginnings、Holton，1931](https://nvlpubs.nist.gov/nistpubs/jres/6/jresv6n5p881_A2b.pdf)：p.893表7的液相焓差公式；p.894说明沸点以下饱和路径导数与常压热容近似对应。已渲染并逐项核对公式，PDF存于references/Fiock-Ginnings-Holton-1931.pdf。
- [NBS SP300卷3](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nbsspecialpublication300v3.pdf)：美国国际焦耳按1.000165换为绝对焦耳。

## 分段模型

`EthanolThermodynamics`以25℃液体焓为零，单位J/g。范围为−15℃至78.35℃、近常压液相，不包括汽相、固相或混合物。

1. −15至25℃沿用112.4 J/(mol K)的**定热容教学近似**，不是各温度均有实测点。
2. 25至40℃在两端热容间线性插值。此桥接是项目近似，不是原论文拟合。
3. 40至78.35℃采用原文多项式焓差，经单位换算并接上40℃基准，保证焓和热容连续。原始数据的40–110℃范围未被下延；当前液体接口也不越过常压沸点。

高温支路原始积分式为`F(t)=22.648(t/10)+0.3053(t/10)^2+0.014233(t/10)^3`，取差后由国际J/g转换为J/g。热容取它的解析导数，反函数用单调区间二分。混温先按转移质量加权比焓，再求温度，不平均温度。

## 已接入与限制

纯乙醇源液与纯乙醇接收液的倾倒预览、撤销和最终混温使用该曲线。压力超出1.01325±0.005 bar、超温、含水或其他物种不会使用该专用路径；原有混合物的独立近似与警告保留。

纯乙醇现已接入常压能量蒸馏/回流：净供热先增加液相焓，再按汽化潜热产生饱和蒸气；变热容冷凝积分决定凝结量和过冷焓。源瓶按实际汽化量扣库存，接收/回流按质量加权焓混合，未凝结乙醇计入逸散质量及携带焓账本。相态表已统一78.35℃，热学路径拥有温度推进，避免原定性加热/冷却重复处理。温度双精度缓存遇外部改温/改库存失效；输出到界面仍为float。

密度沿用现有物性体积账本，不虚构热膨胀；功率/UA仍为教学设定，外壁绝热、无玻璃蓄热。接收瓶须为空或适用温区的纯乙醇，混合接收物拒绝并保持库存。接收容量限制按最坏全部凝结预留，满载/烧干停止，未使用供热单列。饱和入口不使用气相热容占位值处理过热。液膜仍仅动画。

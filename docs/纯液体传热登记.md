# 纯液体传热登记

## 实现范围

`PureLiquidThermalModel` 显式注册物质，不按“醇类”等类别猜测物性。水保留原独立路径；乙醇和甲醇共用纯液体供热/汽化/冷凝/接收/回流算法，文件暂仍名为 `EthanolCondenser.cs`。温度双精度缓存同时识别物种、质量与界面改温。界面单精度沸点若向上舍入，显示值略向下保留，避免独立物态引擎未经潜热支付先把整瓶转为气体；能量积分仍保留原双精度温度。

## 甲醇来源与近似

- [NIST SRD69 甲醇相变表](https://webbook.nist.gov/cgi/cbook.cgi?ID=C67561&Mask=4)：摩尔质量32.0419g/mol；Majer/Svoboda1985条目在337.7K的汽化焓35.21kJ/mol。本模型选与此匹配的64.55℃作为常压汽化温度，接近页面平均沸点337.8±0.3K；不把标准态汽化焓误用为沸点值。
- [NIST 甲醇液相热容表](https://webbook.nist.gov/cgi/cbook.cgi?ID=C67561&Mask=7EF)：Khasanshin/Zykova1989条目在298.15K给出81.11J/(mol·K)。本项目把该室温值用于0–64.55℃的**定热容教学近似**，并非声称该温区热容不变或已完成变温拟合。
- 以25℃液体比焓为零，h=Cp×(T−25)，单位J/g；汽化潜热35210/32.0419J/g。甲醇相态表另采用NIST平均熔点176K（−97.15℃），与供热模型的0℃下界不是同一含义；零度以下可有液体，但当前热量模型不外推。

乙醇继续使用 `乙醇热物性.md` 中的分段变热容模型，未降级成甲醇的定热容近似。两种纯液体同种倾倒按各自焓混合；混合物、缺数据物种和非近常压不套用该模型。

## 反应热与量热共用焓模型

纯甲醇、纯乙醇的 `Lab.ApplyReactionHeat` 现在按 Q=−nΔH 增加液相总焓，再反求温度；`EnergyFromTemp` 按质量乘焓差计算，`EnthalpyFromTemp` 返回 −Q/n。二者的 v.Temp 明确定义为初温，dT为目标温差，不改库存。`TryHeatCapacity` 返回当前温度的局部热容，不能将其直接当作大温差的平均热容。

输入仍须是纯液体、近常压和有数据温区。反应计算后的混合溶液不借用纯物质曲线；水溶液/水乙醇混合物原有明确标注的近室温近似保留。热量将温度推过沸点/低温边界时当前入口拒绝且保留原温度，注明相变潜热未处理；蒸馏器的汽化潜热路径独立存在。这并非所有反应热和混合物均已物理统一，也未补造缺失的反应焓。

PureLiquidCalorimetryAudit覆盖两物种四初温×三温差的焓积分、正反计算和局部热容，以及越界、压力、NaN/Infinity、量级溢出、水路径回归；温度检查包含float写回误差，不将UI单精度误差当作新增能量。

## 验证及剩余限制

PureLiquidCondenserAudit 95/95：来源单位换算、18组真实Lab.Tick、30秒、蒸馏/回流、三档冷却水及1/0.1/0.01秒步长；验证质量/能量、相态引擎不抢先蒸发、物种独立逸散账本和倾倒撤销。乙醇整机100/100回归。冷却剂水热容、密度和UA/供热仍使用此前明确的教学假设；混合物气液平衡、装置热惯性、外壁散热和其他有机物仍待实现。液膜物理不在要求内。

# 冷凝传热实现记录

## 用户范围

需要完整冷凝传热；不做液膜流体力学。管内液膜着色器只表示流动，不计第二份液体库存。器皿 GPU 流体要求不变。

## 已实现的独立求解器

`Assets/Scripts/Chem/CondenserHeatTransfer.cs`：纯蒸气入口、逆流冷却剂、稳态、给定总热导 UA 的三段换热求解。气相/冷却剂定比热容，液相可选定比热容或有界的变热容焓表。三个区段不预先分配固定面积，而是在试算热流时分别积分需要的热导。

输入单位：流量 kg/s，潜热 J/kg，比热容 J/(kg·K)，温度 ℃，总热导 W/K。求解器不内置虚构的物性或声称已标定的仪器参数。

以饱和液体比焓为零：液态 h<0，气液共存 0≤h≤L，气态 h>L。用各相比热容将比焓转换为温度。在气液共存区保持饱和温度，但汽相质量分数随 h/L 变化。

给定总移热率 Q，沿蒸气入口起算的已移热率为 q：

- 热侧比焓：h(q)=h_in−q/ṁ_hot。
- 逆流冷侧温度：T_c(q)=T_c,in+(Q−q)/(ṁ_c·Cp_c)。
- 所需热导：UA_required=∫dq/[T_h(h(q))−T_c(q)]。

按去过热、冷凝、过冷三个线性/等温区段精确积分对数平均温差，二分寻找满足给定 UA 的 Q。局部温差≤0视为温差极限，不允许温度交叉。二分返回可行下界，避免浮点舍入到温差为零、造成虚假的无限热导。

输出：移热功率、冷却剂出口温度、热侧出口温度、汽相质量分数、凝结/未凝结质量流率，以及三段热负荷。冷热两侧热量相等，凝结与未凝结流率之和等于入口蒸气流率。

设计依据：[NPTEL，Condenser and Reboiler Design：De-superheating and sub-cooling](https://archive.nptel.ac.in/content/storage2/courses/103103027/module1/lec6/2.html)。分段积分和数值求根为本项目实现，不代表该资料提供了本装置的实测 UA。

## 验证与明确未完成部分

`CondenserThermalAudit` 使用明确标记的合成物性来隔离验证数学求解器，不把这些数值称为水或有机物实测数据。包含相变 NTU 解析解、单相逆流 NTU 解析解、三段分配、质量/能量守恒、流量与热导极限、无冷却流、热冷却剂及非法输入。

## 变热容求解器增量（2026-09-23）

新增不可变 `LiquidEnthalpyCurve`，以饱和液体焓为零，按 h(T) 分段线性插值和反求温度；过冷段在每个焓节点拆分，逐段积分温差，因此包含内部温差夹点。曲线必须覆盖冷却剂入口至饱和温度，越界拒绝、不外推。拒绝非有限/非单调节点及归一化丢失精度。即使提供曲线，兼容字段 LiquidCpJPerKgK 仍须为正数，但不参与该液相求解。

乙醇采用 `EthanolThermodynamics` 已注明范围的液相焓模型（详见乙醇热物性.md），默认不超过0.25℃节点间隔，包含25/40℃分支边界。独立审计219/219：原98项、定热容表与原解析路径对照、非法曲线、乙醇36组冷却条件、0.5/0.25/0.125℃网格收敛。默认与细网格最大差约0.0000251W/0.00000610℃，与乙醇解析液相焓残差最大0.0000180W；这些仅是所测范围的数值一致性，不代表实物精度。证据 condenser-curve-final.log / condenser-thermal-audit.txt。乙醇仅测试饱和蒸气，不把正占位气相热容用于过热条件。

随后新增 `EthanolCondenser.cs` 已把纯乙醇接入整机汽化、库存、回流和逸散账本，并通过显式 `PureLiquidThermalModel` 登记扩展到甲醇；纯水原路径保持。具体范围及来源见乙醇热物性.md、纯液体传热登记.md。其他有机物/混合物不因此自动获得完整传热。

## 纯水运行时接入（2026-09-23）

`WaterCondenser.cs` 已接入 `DistillationAssembly.Tick`：0–100℃纯水源瓶及纯水/空接收瓶、常压条件下，先按净加热功率给液体显热，再按汽化潜热生成饱和蒸气。只有实际产生蒸气的时段参与冷凝计算；接收容量/干烧上限拒绝多余加热量。冷凝液按实际出口温度与接收水/回流水做显热混合。未凝结蒸气从开口边界离开，质量与携带的焓保留在累计账本。

水汽化潜热取100℃的2256.4 kJ/kg，来源为[NIST IAPWS-95蒸汽表](https://tsapps.nist.gov/publication/get_pdf.cfm?pub_id=906704)。液水与冷却水使用项目已有4.18 J/(g·K)定比热容近似，水库存沿用1 g对应1 mL的既有体积近似。入口严格为饱和蒸气，气相比热容不参与此路径；传入求解器的正占位值不是蒸气实测热容，不能拿它用于过热蒸气。

参数菜单可改变净供热功率、冷却水质量流量、入口温度和UA，并查看热量账本。默认250 W、10 g/s、UA=10 W/K明确是教学设定，**不是通过实际模型几何或实验标定得到的值**。锅炉/接收瓶外边界暂按绝热处理；此路径避开旧26℃/s、定比例室温冷却、固定2.6mL/s蒸发及本生灯重复升温。液膜动画仍只跟随实际冷凝量。

本生灯控制补充：源瓶直接吸附本生灯或置于三脚架上的本生灯加热范围内时，参数菜单的功率是火力50%时的基准净功率，运行时按`基准功率 × 火力 / 0.5`线性缩放；灯熄灭、火力低于12%、移出范围或火焰达不到支撑高度时供热为零。三脚架下无灯时不能回退到独立加热器。仅无物理支撑/本生灯的装置保留独立教学加热功率。普通容器的热源识别、加热反应推进及卡片火力入口使用同一位置判定，避免重复加热。这仍是教学控制映射，不是实测燃气流量、燃烧焓或对流/辐射耦合标定：间接供热范围沿用水平0.22世界单位及火焰上方0.10单位接触容差，不求解未接触火焰的热羽流。右键本生灯的火力弹窗直接改变控制量，不要求操作模型旋钮。

**完整冷凝传热仍未完成**：除纯乙醇以外的有机物和混合物仍使用明确提示的旧演示流量分支，需要继续接入有来源及适用范围的各相热物性、多组分饱和条件、相应的供热/逸散/混合焓；纯水的定比热容/恒密度也需按精度要求完善。与实际装置几何对应的换热参数、壁面及冷却水热惯性、外壁散热尚未实现。长时间/细时间步能量误差、实际本生灯吸附和多分辨率传热参数操作仍需扩验。液膜流体力学不在要求内。

物性来源：NIST [乙醇](https://webbook.nist.gov/cgi/cbook.cgi?ID=C64175&Mask=4)已结合液相焓资料接入上述专用路径；[乙醛](https://webbook.nist.gov/cgi/cbook.cgi?ID=C75070&Mask=4)、[丁醛](https://webbook.nist.gov/cgi/cbook.cgi?ID=C123728&Mask=4)相变表已开始核对但尚未接入能量求解。不同温度的汽化焓不能未经说明混用，更不能用汽化焓代替气/液相比热容。

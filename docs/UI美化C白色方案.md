## 实际截图发现并修正的问题

- 计算器原有白色连线在浅底难以辨识：改黑色实线、深青色拖线；不匹配的物质节点保留红色边框反馈，而非丢弃错误状态。
- 助手发送/收起按钮原本错误锚定顶部，已改到底部；输入框缩进修正，消息气泡按实际文本测量高度，增高输入框时同步压缩消息视口。
- 助手设置菜单原本跳过所有无动作项目，导致状态、端点和模型不可见，现恢复这些信息行及关闭入口；空端点补英文文本。测试只使用内存空配置，不显示真实密钥或请求外部服务。
- 助手闲聊气泡按翻译后文本测高，并限制在画布内，修复左侧气泡越界。
- 实际截图发现本生灯、量器、热量账本在 LateUpdate 中重新写入中文，早于该阶段采样的双语测试未捕获。改为写入时直接本地化，随后复核实际渲染，不能以旧无漏译断言替代此修复。

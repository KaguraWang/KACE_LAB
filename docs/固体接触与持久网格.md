# 固体接触与持久网格（第3项进行中）

## 当前实现

- `SolidBodySeed` 从生成可见网格的同一次循环取得粗粒、絮状物、冰块的质量、体积、朝向后顶点和顶点区间。粉末床仍为静态连续网格。
- `SolidTranslationState` 持续保存位移、速度、实际网格浸没体积和浮心；缓存256区间的一阶矩，不每个子步遍历三角形。
- `SolidVesselBoundary` 处理当前小步的侧壁、底和狭嘴，使用保守包围柱快速接受远离壁面的情况，临界处仍检查实际顶点。不是任意高速穿越的连续碰撞检测。
- `SolidContactShape` 将可见网格的顶点烘焙为凸包接触模型。只用于固体之间接触；质量、排液体积仍用原始不规则网格，不以凸包体积取代。细小凹坑的接触采用凸包近似，尚未实现角运动。
- 接触模型位于独立的本地物理场景，不在主场景拾取/触发器查询中。该场景不自动推进固体；指定姿态的接触查询和自定义状态求解负责运动。
- `SolidBodyBatch` 将浮力、壁约束、最多8轮质量加权去穿透与完全非弹性法向冲量组合，按同一状态更新原网格顶点。不会重建外形或改变UV/法线；暂停时保持状态和网格。

接口依据：[Unity ComputePenetration](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/Physics.ComputePenetration.html)、[CreateSceneParameters](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/SceneManagement.CreateSceneParameters.html)。实际Player发现禁用MeshCollider后不能得到有效接触形状，因此改为独立物理场景，而不是仅将enabled设为false。

## 验证与限制

粉末床现在由 PowderBed 在合并台面溢出网格之前输出器皿内部 IsStatic 种子。其完整实际三角网格进入 GPU 障碍和浸没体积缓存；床顶用于移动颗粒的支撑约束，不给床分配运动/接触代理。床仍为不可移动沉积层，不是粉末颗粒冲散模拟。SolidBodyBatch.Count包含静态种子，State(i)可为空；CopyActiveObstacles/Positions包含静态床但排除溢出颗粒。solid-powder-player.log实际视图8/8，状态/原移动种子回归69/69。完整普通功能回归451/451是在此粉末床更改之前，不能冒充之后的完整回归。

融化重建入口：`SolidGeometry.Build(v,seeds,previous.Seeds)` 后 `new SolidBodyBatch(kind,mesh,seeds,previous)`，成功后再由调用方释放旧批次及网格。减量时保持同物质/相的数量，重建按组内序号匹配，保留旧中心速度及同朝向不规则表面，按新体积立方根缩放；不修改旧批次。增长后放不下旧中心时尝试整体边界解算，失败使用新生成的安全形状位置，不保证增长毫无位置调整。新形状法线和切线重建，UV材质编码不变。实际61/61见solid-remap-final-player.log，包含跨块数阈值半融化7项；这还不是主场景连续融化/加料完整验收。

2026-09-24 新增 SolidLiquidLevel，积分与 GPU 相同的513半径剖面，按内腔减去各持久固体实际浸没体积，二分解出给定液体库存的静水平面。StepWithLiquidVolume 每个1/240秒子步更新液面，再推进固体，再重新闭合体积。解算不修改化学库存，容量不足返回 ExcessLiquidMl，不能把返回值当作已经发生溢出。要求输入固体已在内腔且不重叠；当前不含粉末床和自由表面波动，也不是已完成GPU双向反馈。

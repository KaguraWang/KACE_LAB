# 小水怪主题

顶部“设置”打开独立设置界面，目前只有“外观 / 主题”，以后可继续添加设置分组。提供“经典白色”和“小水怪”，点击即时生效并以 `KaceLab.Appearance.Theme` 保存到 PlayerPrefs；默认保留经典主题。

主面板使用三张不同插画，保留白色卡片、黑色文字、青色输入框与选中按钮。背景不接收点击，不改化学/模拟行为。设置界面打开时屏蔽实验台操作；返回或 Escape 关闭。

图片由内置 imagegen 生成，素材路径 `Assets/Resources/Themes/Nessie/{Shelf,Log,Settings}.png`。最终提示词：参考用户绿色小水怪，粗黑轮廓、明快平涂、圆润长颈和短鳍、奶黄色腹部、闪亮大眼与小 W 形嘴；不要鼻子或鼻孔，不要水彩。整图密集堆满不同姿态的小水怪；分别绘制竖向相拥、横向游泳派对、方形花朵聚会构图，无文字或 UI。早先水彩图未采用。

指定三维模型见 `ArtSources/Nessie/README.md`，其外观独立于 UI 插画，未替换现有助手或场景模型。

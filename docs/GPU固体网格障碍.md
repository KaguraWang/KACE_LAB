# GPU 固体网格障碍阶段记录

## 对称邻域速度平滑（2026-09-24）

参考[PBF原论文的速度后处理](https://mmacklin.com/pbf_sig_preprint.pdf)，补上GPU邻域黏性平滑。这里具体归一化为 `a_ij = ParticleVolume * W(x_i-x_j) / max(1, row_i, row_j)`，`row_i`为邻域核权重和，最终`v_i += c * sum(a_ij*(v_j-v_i))`。权重对称、行和≤1，c在0..1时是凸混合，因此等质量系统保持总线动量且动能不增加。当前c=.03/90Hz步，并非Pa·s物质黏度；未宣称保持角动量或完成真实溶剂/温度黏度校准。

去掉原Velocity对所有速度统一乘0.985的衰减，保留既有4世界单位/s速度限幅。最后一次位置修正后重建邻居索引；Velocity输出原速度并缓存核行和到已不再使用的L，Viscosity读V写D，再独立Commit写回V，不作有竞争的原地更新。生产不增加CPU回读。

新增GPU测试：匀速移动、随机速度、高度聚集位置三模式×0/.03/1强度，检查hash与all-pairs、线动量/动能、匀速和关闭状态不变、相对速度确实耗散，27/27通过。最大参考差9.6571e-7，平均动量误差最大1.4228e-8。fluid-viscosity普通构建成功，GPU总69/69、View11/11、完整451/451；94内部体600实际帧P95 16.671/max17.965ms，边界及原形重叠通过；普通四器皿P95 16.7049/max17.24。新截图已查看，仍存在局部拉丝/不平顺，不把平滑阶段的守恒当整个求解器或最终视觉验收通过。

## 固体边界密度与梯度首版（2026-09-24）

SolidNearestSurface沿现有原始网格两层BVH查询核半径内最近三角形，不拿AABB表面替代原网格。FluidBoundaryKernel计算归一化3D poly6核在最近切平面内的半空间积分及位置梯度；Density将固体/原器壁贡献取最大值、加入约束和梯度分母，Correct加入对应位置修正。不会增加液体粒子或库存。

该实现明确是局部平面近似：曲面、多个邻近固体及夹角的真实占据核体积尚未积分，取max不代表精确并集；也未把反作用力传回固体。后续完整方向参考研究组的[Density Maps](https://animation.rwth-aachen.de/media/papers/kb17.pdf)与[Volume Maps](https://animation.rwth-aachen.de/publication/0565/)，当前并未实现这些论文的完整算法。

新增6面×5距离×移动前后GPU检查，与解析盒面距离和CPU Simpson半空间积分比较。初版法线因世界坐标重减误差失败，改保留局部p-q后未放宽容差即通过：最大距离差3.18e-8世界单位、法线差5.97e-8、梯度差2.87e-6。

逐Density迭代查询最近网格的性能试验失败：94体实际600帧P95 87.1154/max534.6818ms，边界和碰撞仍通过。改为每90Hz步Predict查询并缓存局部平面，4轮约束按更新位置重新计算解析积分和梯度；精确固体碰撞仍每轮执行。此线性化也不是跨步固定边界或减少物理步数。

fluid-boundary-plane普通构建成功，GPU40、View11、完整451通过；94体600实际帧P95 16.6851/max17.2689ms，0越界/原形重叠门槛通过；普通四器皿P95 16.6977/max16.9352。最后新增实际缓冲审计，fluid-boundary-final构建/GPU42通过，210粒子实际接受有限边界梯度，移除固体后边界贡献全0，18432渲染命中仍0原形内部。缓冲随solver释放，无生产CPU回读。截图已查看仍有不平顺和局部拉丝，不能算最终视觉验收，整体动态仍默认关闭。

## 未验证或尚未实现

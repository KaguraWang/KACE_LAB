# 冰水转移与潜热

`IceWaterTransfer` 复用已有 WaterIce 的常压纯水近似及已有0–100℃液水定热容模型：冰最低−10℃，无冰纯液水可至100℃，水热容4.18J/(gK)、冰热容2.1J/(gK)、熔化潜热333.5J/g，来源仍见 WaterIce/WaterCondenser代码。热水与冰混合也必须先支付熔化潜热，不受旧WaterIce入口40℃上限截断。此次未引入新物性数据或混合溶液凝固点假设。

零度冰为焓零点。液水转移携带 m×(L+Cp水×T)，冰转移携带 m×Cp冰×T；与接收器原焓相加，按总质量求最终相比例与温度。焓在0至mL之间时保留0℃冰水共存，不把所有冰瞬间融化。计算不改变化学反应进度。

接入分阶段倾倒、普通比例转移及移液管/滴定管液体通道。固体量和液体量独立选择；量器只取液体，不把冰当液体吸入。分阶段预览从原快照重新预测，飞行中只加入已经到达部分的能量，撤销恢复原相比例/温度，提交不重复融化。容量同时检查最终状态和当前到达状态，考虑结冰体积增长；拒绝不改库存。若动画中途校验失败，恢复原状态、清理飞行物并提示重选，不能继续提交残留飞行库存。

IceWaterTransferAudit覆盖冷冰与温水两个方向、部分/完全融化、80℃热水、质量与焓守恒、预览/撤销/提交、半途飞行、未到达不能提交、普通转移、量器抽放和冻结膨胀硬上限。混合物/加压/超温不套纯水结果；粒状冰的浮力、形状和融化表面视觉仍待完善，不把库存热量正确当作液膜或浮冰物理全部完成。

## 七、本次执行中发现并修复的引擎缺陷

这些是跑用例时**真实暴露**出来的问题，不是推测：

1. **气体产量虚高 50%（影响全引擎）**：`Apply` 里气体既按化学计量 `Produce` 了一次，
   又按特效字段 `gas` 额外加了 `extent * 0.5`。实测 `Mg + 2H+ -> H2` 中 0.0070 mol Mg
   产出 0.0105 mol H₂（恰好 1.5 倍）。所有放气反应的产量此前都是错的。
2. **方程式电荷解析两次出错**：贪婪正则把 `MnO4-` 读成 `MnO` + 电荷 −4（下标被当电荷）；
   改成一律取结尾数字当电荷后又把 `NH4+` 读成 `NH` + 电荷 +4。
   最终判据：「剥掉结尾数字后剩下的是否为单个元素符号」—— 是则数字是电荷，否则是下标。
3. **浓/冰态变体在无水条件下对不上**：`ch3cooh_glacial` 的 `MoleculeAs = ch3cooh`，
   有水时经电离路径统一，无水时原样存储 → 规则里的 `CH3COOH` 找不到它，酯化永不发生。
4. **弱碱电离被自己的逆反应吃掉**：`NH4+ + OH- -> NH3 + H2O` 有一条**无任何条件**的规则，
   NH₃ 刚电离出的 OH⁻ 立刻被逆转消除，银镜反应（需 2OH⁻）永远不触发。已加热条件。
5. **温度门槛缺失**：乙醇脱水只判「有浓硫酸」，80 ℃ 的酯化实验里会错误生成烯烃。
   已加 `catal_hot`(≥140 ℃) 与 `catal_warm`(≥55 ℃) 两个温度敏感条件。
6. **新物种缺电离条目**：`kio3`、`na2s2o3` 加进了物质表却没加电离表，
   于是 `IO3-` 与 `S2O3^2-` 从未生成，碘量法两步反应全部不触发。
7. **一条恒真的负向测试**：原先「氯离子干扰」用等量高锰酸根，而它会被 Fe²⁺ 恰好消耗光，
   根本没有余量去氧化 Cl⁻ —— 断言 `MnO4- ≈ 0 and Cl- > 0` 恒成立、什么都没测到。
   改为**过量**高锰酸根后，实测 Cl⁻ 消耗 1.25 mmol、生成 625 µmol Cl₂，干扰才算被验证。
8. **滴定数据处理**：原先完全没有；`batch_eval` 在找不到一致组时提前返回，
   导致「数据不一致」这一负向结论拿不到统计量。已改为无论如何都输出统计量。
